# 12. BMI Calculator

Boy ve kiloya göre vücut kitle indeksini (BMI) hesaplayan ve kategoriye ayıran araç.

## Çalıştırma

```bash
python3 bmi_calculator.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 12-bmi-calculator/index.html   # macOS
xdg-open 12-bmi-calculator/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
