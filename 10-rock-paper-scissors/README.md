# 10. Rock Paper Scissors

Taş kağıt makas oyunu. Bilgisayara karşı oynanır ve skor tutulur.

## Çalıştırma

```bash
python3 rock_paper_scissors.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 10-rock-paper-scissors/index.html   # macOS
xdg-open 10-rock-paper-scissors/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
