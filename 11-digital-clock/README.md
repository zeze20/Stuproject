# 11. Digital Clock

Terminalde saniyesi saniyesine güncellenen gerçek zamanlı dijital saat.

## Çalıştırma

```bash
python3 digital_clock.py
```

Durdurmak için `Ctrl+C` tuşlayın.

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 11-digital-clock/index.html   # macOS
xdg-open 11-digital-clock/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
