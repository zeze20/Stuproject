# 2. To-Do List (CLI)

Komut satırında çalışan, görevleri JSON dosyasında saklayan basit bir yapılacaklar listesi uygulaması.

## Çalıştırma

```bash
python3 todo.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 02-todo-list-cli/index.html   # macOS
xdg-open 02-todo-list-cli/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
