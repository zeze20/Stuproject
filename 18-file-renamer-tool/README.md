# 18. File Renamer Tool

Bir klasördeki dosya isimlerini toplu olarak değiştiren araç. Değişiklikten önce önizleme gösterir.

## Çalıştırma

```bash
python3 file_renamer.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 18-file-renamer-tool/index.html   # macOS
xdg-open 18-file-renamer-tool/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
