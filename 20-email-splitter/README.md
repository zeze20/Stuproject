# 20. Email Splitter

E-posta adreslerini kullanıcı adı, alan adı ve uzantı parçalarına ayıran araç.

## Çalıştırma

```bash
python3 email_splitter.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 20-email-splitter/index.html   # macOS
xdg-open 20-email-splitter/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
