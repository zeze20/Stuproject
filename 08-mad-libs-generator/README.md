# 8. Mad Libs Generator

Kullanıcının girdiği kelimelerle (isim, sıfat, fiil vb.) komik bir hikaye oluşturan uygulama.

## Çalıştırma

```bash
python3 mad_libs_generator.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 08-mad-libs-generator/index.html   # macOS
xdg-open 08-mad-libs-generator/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
