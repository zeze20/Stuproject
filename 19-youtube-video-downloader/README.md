# 19. YouTube Video Downloader

`yt-dlp` kullanarak video indiren araç.

> **Not:** Yalnızca kendi videolarınızı veya indirme izniniz olan / telif hakkı sorunu olmayan içerikleri indirin. Telif haklarına ve YouTube'un kullanım koşullarına uymak sizin sorumluluğunuzdadır.

## Kurulum

```bash
pip install -r requirements.txt
```

## Çalıştırma

```bash
python3 youtube_downloader.py
```

Videolar `downloads/` klasörüne indirilir.

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 19-youtube-video-downloader/index.html   # macOS
xdg-open 19-youtube-video-downloader/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
