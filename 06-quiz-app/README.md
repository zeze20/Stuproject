# 6. Quiz App

Çoktan seçmeli sorulardan oluşan basit bir quiz uygulaması. Sonunda toplam skor gösterilir.

## Çalıştırma

```bash
python3 quiz_app.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 06-quiz-app/index.html   # macOS
xdg-open 06-quiz-app/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
