# 3. Dice Roller

Zor atma simülasyonu. 1-6 arası rastgele sayı(lar) üretir, birden fazla zar atmaya izin verir.

## Çalıştırma

```bash
python3 dice_roller.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 03-dice-roller/index.html   # macOS
xdg-open 03-dice-roller/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
