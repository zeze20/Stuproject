# 9. Currency Converter

Sabit kur tablosu kullanan basit döviz çevirici uygulaması (USD, EUR, TRY, GBP, JPY).

## Çalıştırma

```bash
python3 currency_converter.py
```

Güncel kurlar için `RATES_TO_USD` sözlüğündeki değerleri güncelleyebilirsiniz.

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 09-currency-converter/index.html   # macOS
xdg-open 09-currency-converter/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
