# 7. Tip Calculator

Hesap tutarı, bahşiş yüzdesi ve kişi sayısına göre toplam ve kişi başı ödemeyi hesaplayan basit uygulama.

## Çalıştırma

```bash
python3 tip_calculator.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 07-tip-calculator/index.html   # macOS
xdg-open 07-tip-calculator/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
