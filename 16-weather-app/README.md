# 16. Weather App (API)

OpenWeatherMap API'sini kullanarak hava durumu bilgilerini çeken uygulama.

## Kurulum

```bash
pip install -r requirements.txt
```

[OpenWeatherMap](https://openweathermap.org/api) üzerinden ücretsiz bir API anahtarı alın ve ortam değişkeni olarak ayarlayın:

```bash
export OWM_API_KEY="senin_api_anahtarin"
```

## Çalıştırma

```bash
python3 weather_app.py
```
