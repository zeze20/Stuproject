# 16. Weather App (API)

OpenWeatherMap API'sini kullanarak hava durumu bilgilerini çeken uygulama.

## Kurulum

```bash
pip install -r requirements.txt
```

[OpenWeatherMap](https://openweathermap.org/api) üzerinden ücretsiz bir API anahtarı alın ve ortam değişkeni olarak ayarlayın:

```bash
export OWM_API_KEY="senin_api_anahtarin"
```

## Çalıştırma

```bash
python3 weather_app.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 16-weather-app/index.html   # macOS
xdg-open 16-weather-app/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
