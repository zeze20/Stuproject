# 15. Alarm Clock

Belirtilen saatte (HH:MM:SS) alarm çalan basit komut satırı uygulaması.

## Çalıştırma

```bash
python3 alarm_clock.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 15-alarm-clock/index.html   # macOS
xdg-open 15-alarm-clock/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
