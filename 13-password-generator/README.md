# 13. Password Generator

Güçlü ve rastgele şifreler üreten araç. Uzunluk, rakam ve sembol seçenekleri yapılandırılabilir.

## Çalıştırma

```bash
python3 password_generator.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 13-password-generator/index.html   # macOS
xdg-open 13-password-generator/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
