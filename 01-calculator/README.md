# 1. Calculator

Temel matematik işlemlerini (toplama, çıkarma, çarpma, bölme) yapan basit bir komut satırı hesap makinesi.

## Çalıştırma

```bash
python3 calculator.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 01-calculator/index.html   # macOS
xdg-open 01-calculator/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
