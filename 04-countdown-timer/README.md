# 4. Countdown Timer

Geri sayım başlatan basit bir zamanlayıcı. Saniye cinsinden süre girilir ve MM:SS formatında geri sayılır.

## Çalıştırma

```bash
python3 countdown_timer.py
```

## Web arayüzü

Bu proje için tarayıcıda çalışan güzel bir arayüz de var:

```bash
open 04-countdown-timer/index.html   # macOS
xdg-open 04-countdown-timer/index.html   # Linux
```

Ya da dosyayı doğrudan tarayıcında açabilirsin.
